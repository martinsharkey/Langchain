## Running the Dashboard

### Option 1: Start Flask Directly

```bash
cd langchain
python -m flask --app dashboard.app run --port 5000
```

Then open: http://localhost:5000/v2

### Option 2: Use Existing App

If you already have `app.py` running, the dashboard is available at:
http://localhost:5000/v2

### Option 3: From Main Entry

```bash
cd langchain
python app.py
```

The dashboard will be available at:
- Old dashboard: http://localhost:5000/
- **New dashboard v2: http://localhost:5000/v2**

## Architecture

```
Dashboard v2 Request Flow:

User opens http://localhost:5000/v2
          ↓
Flask serves dashboard_v2.html
          ↓
Page loads JavaScript (vanilla, no npm needed)
          ↓
JavaScript calls /api/v2/strategies, /api/v2/summary, etc.
          ↓
Backend API aggregates data from:
  - strategy_config.json (generated by edge_discovery)
  - edge_weights.json (vectorbt discoveries)
  - trading_experience.db (live performance)
  - bot_status.json (account state)
          ↓
JSON response
          ↓
JavaScript renders to DOM
          ↓
Dashboard displays live data
```

## Troubleshooting

### Dashboard doesn't load
1. Check Flask is running on http://localhost:5000
2. Verify `/v2` route exists: `curl http://localhost:5000/v2`
3. Check browser console for errors (F12 → Console tab)
4. Verify API is working: `curl http://localhost:5000/api/v2/summary`

### API returns errors
1. Check `trading_experience.db` exists in `data/` directory
2. Check `strategy_config.json` exists (generated by edge_discovery)
3. Check `edge_weights.json` exists
4. Check logs for API initialization messages

### No data showing
1. Open browser developer tools (F12)
2. Go to Network tab
3. Look for failed requests to `/api/v2/*`
4. Check Console tab for error messages
