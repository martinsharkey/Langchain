## How to Run

### Prerequisites
- Node.js 16+ or pnpm 8+
- Backend running on localhost:5000

### Development

```bash
cd dashboard-frontend
pnpm install
pnpm run dev
```

Open http://localhost:3000

Dev server automatically:
- Proxies /api to backend
- Hot-reloads on file changes
- Type-checks as you type

### Production Build

```bash
cd dashboard-frontend
pnpm run build
```

Output in `../dashboard/public/` (ready to serve)

## Integration with Existing Flask App

To wire into the main Flask app:

```python
# In dashboard/app.py or main app.py

from src.dashboard.api_v2 import initialize, get_api
from src.dashboard.routes_v2 import register_routes

# On app startup
db_path = "path/to/trading_experience.db"
config_dir = "data/"
initialize(db_path, config_dir)
register_routes(app)  # Adds /api/v2/* routes
```

Then:
- Backend serves API at /api/v2/*
- Frontend builds to ../dashboard/public/
- Serve static files for /dashboard path
- API client transparently fetches from backend

## Data Flow

```
User opens Dashboard
      ↓
React calls /api/v2/strategies
      ↓
Backend aggregates from:
  - strategy_config.json (generated by edge_discovery)
  - edge_weights.json (vectorbt discoveries)
  - trading_experience.db (live performance)
      ↓
JSON response
      ↓
React renders to DOM
      ↓
User clicks row → Detail panel updates
```

## Architecture Benefits

1. **Separation of Concerns**
   - Backend: data aggregation & business logic
   - Frontend: visualization & user interaction
   - No tight coupling

2. **Maintainability**
   - React components are small, reusable, testable
   - TypeScript prevents runtime errors
   - CSS organized with Tailwind utilities

3. **Performance**
   - Vite build is fast (~1s)
   - HMR for instant feedback
   - Lazy loading ready for future code-splitting

4. **Scalability**
   - Easy to add new pages, components, endpoints
   - State management ready (Zustand for future)
   - API client easily extends

## Deployment

When ready to deploy:

1. Build frontend: `pnpm run build`
2. Copy `dashboard-frontend/dist/*` to `dashboard/public/`
3. Update Flask to serve static files from `dashboard/public/`
4. Initialize API: `initialize(db_path, config_dir)` on app startup
5. Deploy normally

Users access at: `http://your-server/dashboard`
